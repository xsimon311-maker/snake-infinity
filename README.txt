SNAKE INFINITY — VERSION INSTALLABLE (PWA)

IMPORTANT
Cette version est préparée pour être installée comme une application web progressive (PWA).
Pour que l'installation fonctionne, le jeu doit être hébergé sur une adresse HTTPS.
Un fichier HTML ouvert directement depuis le téléphone ne peut pas activer le service worker ni fonctionner comme une vraie PWA hors ligne.

MÉTHODE SIMPLE AVEC GITHUB PAGES
1. Sur GitHub, crée un dépôt public nommé snake-infinity.
2. Envoie TOUS les fichiers de cette archive en gardant les dossiers (index.html, manifest.webmanifest, sw.js, icons/).
3. Dans Settings > Pages, active le déploiement depuis la branche main et le dossier root.
4. Attends la création de l'adresse HTTPS de ton site.
5. Ouvre cette adresse dans Chrome sur Android.
6. Menu ⋮ > « Installer l'application » ou « Ajouter à l'écran d'accueil ».
7. Confirme. Snake Infinity apparaîtra comme une appli sur ton téléphone et pourra se lancer en plein écran.

Le jeu et sa sauvegarde utilisent le stockage local du navigateur. Évite d'effacer les données du site.
